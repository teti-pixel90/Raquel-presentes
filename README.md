# Raquel Presentes

Site que desenvolvi para a loja Raquel Presentes.

A ideia do projeto é criar um catálogo online onde os clientes possam ver os produtos e fazer o pedido pelo WhatsApp.

## Tecnologias

- HTML
- CSS
- JavaScript

## Funcionalidades

- Catálogo de produtos
- Busca e categorias
- Carrinho
- Pedido pelo WhatsApp
